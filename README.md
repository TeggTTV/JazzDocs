# Welcome to Jazz Docs👋
This project is a web-app approach to document editing with user-focused features.

I honestly got tired of using Google Docs and Microsoft Word.

Here’s why:
Microsoft Word: Locked behind a paid Office subscription when free tools exist.
Google Docs: Great features, but after years of staring at a white screen, I feel bummed to open it. A canvas-style editor sucks for developing, and having to install an extension for dark mode is crazy work. 

This tool won't be a Google Doc clone, it will be a tool built specifically for people who want a cleaner, more tailored writing experience. 

## Planned Features

* Native dark mode and full theme customization
* Custom keybindings
* Font flexibility via system fonts and direct file uploads
* Spotify integration for background audio while typing
* User extension ecosystem
* Local-first document storage options
